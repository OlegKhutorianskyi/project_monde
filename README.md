🌐 Project Monde

Project Monde ist eine moderne Webanwendung, die entwickelt wurde, um ein nahtloses und interaktives Benutzererlebnis zu bieten. Das Projekt kombiniert eine saubere Architektur mit einer benutzerfreundlichen Oberfläche.

🚀 Funktionen und Merkmale

🎨 Moderne Benutzeroberfläche: Ansprechendes und intuitives Design für eine optimale Benutzererfahrung.

📱 Responsive Design: Vollständig optimiert für alle Bildschirmgrößen (Mobilgeräte, Tablets und Desktop-PCs).

⚡ Hohe Performance: Schnelles Laden und optimierte Komponentendarstellung.

🛠 Modulare Struktur: Leicht erweiterbarer und wartbarer Codebase.

🛠 Technologie-Stack

Frontend: React / JavaScript (oder TypeScript)

Styling: CSS / SCSS / Tailwind CSS

Build Tool: Vite / Webpack

Version Control: Git / GitHub

📦 Installation und Einrichtung

Führe die folgenden Schritte aus, um das Projekt lokal auszuführen:

1. Repository klonen

git clone https://github.com/OlegKhutorianskyi/project_monde.git
cd project_monde


2. Abhängigkeiten installieren

npm install
# oder
yarn install


3. Entwicklungs-Server starten

npm run dev
# oder
yarn dev


Nach dem Start ist die Anwendung unter http://localhost:5173 (oder http://localhost:3000) erreichbar.

🏗 Produktion-Build

Erstellen eines optimierten Builds für die Bereitstellung (Deployment):

npm run build
